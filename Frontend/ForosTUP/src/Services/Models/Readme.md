# Capa de servicios: modelado

Esta capa del frontend existe para almacenar modelos, es decir, clases de objetos. Un gran problema cuando desarrollamos el front antes fue transmitir toda la información en objetos armados a ojo en vez de usar modelos prearmados para transportar los datos de una capa a otra.

Se me ocurre que tener modelos almacenados fuera de la lógica de componentes de interfaz gráfica puede contribuir a la claridad del código.
